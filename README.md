# Collection Gallery

A public web gallery for a personal "collection of collections", with a private admin
area. Built with Astro on Cloudflare Workers, D1, and R2.

- Specification: [`docs/REQUIREMENTS.md`](docs/REQUIREMENTS.md)
- Progress: [`docs/PROGRESS.md`](docs/PROGRESS.md)
- Security: [`docs/security/`](docs/security/)
- Developer commands: [`CLAUDE.md`](CLAUDE.md#commands)

## Reporting a security issue

Please use GitHub's **private vulnerability reporting** (Security tab → "Report a
vulnerability"). Don't open a public issue.
